# Parsebio SPLITseq and SCEPTRE analysis Pipeline

This repository provides a full pipeline for processing ParseBiosciences single-cell CRISPR perturbation data, including:

1. **Split-pool preprocessing** (`split-pipe v1.2.1` )  
2. **SCEPTRE analysis** (`v0.10.1`) on low MOI data  

It includes scripts for installation, running the pipeline, and post-processing analysis.

## Requirements

### Software

- **Conda** (miniconda/anaconda recommended)  
- **R >= 4.3.1**  
- **Python >= 3.12**  

Required R packages:

- `sceptre`  
- `cowplot`  
- `optparse`  
- `devtools`  

Python packages are installed via the ParseBiosciences pipeline.

### Hardware

- Multi-core system recommended  
- Memory depends on dataset size (10–100 GB recommended)

## Installation

Run the provided `install.sh` script to create a conda environment, install dependencies, and download the reference genome.

```bash
# Usage: ./install.sh [hg38|mm10]
# Default genome: hg38
./install.sh hg38
```

**Steps performed by the script:**

1. Create and activate conda environment `spipe` with Python 3.12.8.  
2. Install ParseBiosciences Pipeline 1.2.1 and its dependencies.  
3. Install R, required R packages, and SCEPTRE via GitHub.  
4. Download reference genome and annotation (FASTA + GTF).  
5. Build reference index using `split-pipe mkref`.

## Input Files

For **split-pool preprocessing** (`run_pipeline.sh`):

| Parameter | Description |
|-----------|-------------|
| `GENOME_DIR` | Directory of reference genome generated by `install.sh` |
| `CHEMISTRY` | 10x chemistry version (e.g., `v2`) |
| `SAMPLE_LIST` | CSV listing samples to process |
| `CRISPR_GUIDES` | CSV with CRISPR guide sequences |
| `FASTQ_DIR` | Directory containing raw FASTQ files |

For **SCEPTRE analysis** (`run_sceptre.R`):

| Parameter | Description |
|-----------|-------------|
| `--gene_mat` | Gene count matrix `.mtx` |
| `--grna_mat` | gRNA count matrix `.mtx` |
| `--all_genes` | CSV listing all genes |
| `--all_grnas` | CSV listing all gRNAs |
| `--grna_target_df` | CSV mapping gRNAs to targets |
| `--pos_pairs` | CSV with positive control pairs |
| `--output_dir` | Directory to save outputs |
| `--rds_file` | Path to save final SCEPTRE object |
| `--n_processors` | Number of CPU cores for parallel execution |

## Running the Pipeline

### 1. Split-Pool Preprocessing

```bash
# Usage:
# ./run_pipeline.sh <GENOME_DIR> <CHEMISTRY> <SAMPLE_LIST> <CRISPR_GUIDES> <FASTQ_DIR>
./run_pipeline.sh ./GRCh38_reference v2 sample-list.txt 300Pilot_guides.csv fastq/
```

**Features:**

- Automatically detects samples from FASTQ filenames containing `WT` or `EC`.  
- Processes WT and EC samples separately.  
- Combines processed WT samples into `TPS_combined/`.  
- Combines EC samples into `gRNA_combined/`.

---

### 2. SCEPTRE Analysis

Run the `run_sceptre.R` script after preprocessing:

```bash
Rscript run_sceptre.R   --gene_mat spipe/TPS_combined/ZIM3/DGE_filtered/count_matrix.mtx   --grna_mat spipe/gRNA_combined/ZIM3/guide_RNAs_filtered/count_matrix.mtx   --all_genes spipe/TPS_combined/ZIM3/DGE_filtered/all_genes.csv   --all_grnas spipe/gRNA_combined/ZIM3/guide_RNAs_filtered/all_guides.csv   --grna_target_df sceptre/grna_target_data_frame.csv   --pos_pairs sceptre/pos_pairs.csv   --output_dir sceptre/   --rds_file RDS/sceptre_all.rds   --n_processors 120
```

## Outputs

**Split-pool outputs:**

- `TPS_combined/` – combined WT samples  
- `gRNA_combined/` – combined EC samples  

**SCEPTRE outputs:**

| File | Description |
|------|-------------|
| `calibration_result.txt` | Calibration check results |
| `discovery_result.txt` | Discovery analysis results with BH-adjusted p-values |
| Other SCEPTRE outputs | QC metrics, assigned gRNAs, intermediate results |
| `sceptre_all.rds` | RDS object containing all processed data and results |
